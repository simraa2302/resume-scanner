 Resume Scanner – AI & Data Analyst Candidate Filter
This Resume Scanner project is a Python-based tool built in Google Colab that automates the filtering of candidate resumes based on skill matching. It supports multiple roles like Data Analyst and AI Engineer, helping recruiters instantly identify top candidates.

 Features
 Upload multiple resumes (PDF, DOCX, etc.)
 Extract and clean resume text using textract
 Match candidates based on predefined skill sets
 Visualize skill match scores for each role
 Display Top 3 candidates per role
 Supports multiple job profiles (e.g., AI Engineer & Data Analyst)
 Easy-to-edit skills list for any job requirement

 
 How It Works
Upload all candidate resumes
Enter the skill sets for roles like:
Data Analyst: Excel, SQL, Power BI, Tableau, etc.
AI Engineer: Python, TensorFlow, NLP, Deep Learning, etc.
Each resume is scored by comparing matched keywords.
The top-scoring candidates for each role are displayed and plotted.


 Technologies Used
 Python 3
 Textract (Resume text extraction)
 Matplotlib (Visualization)
